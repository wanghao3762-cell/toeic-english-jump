# 托业英语跳一跳

主要面向电脑 Chrome：直接打开 **托业英语跳一跳.html**，无需安装或联网加载词库。
建议长期使用同一个浏览器、同一个文件位置；不同浏览器、文件路径、
本地服务器地址可能各自使用不同存档。无痕模式和清理浏览器数据可能丢失进度。

## 当前玩法

- 从山脚营地出发，沿固定登山绳向上；远山与营地随攀升退出画面，50 米绳尺持续提供位置参照。
- 每次落地按实际垂直距离累计攀登足迹；下一轮及刷新后从已保存的高度继续。
- 100 / 300 / 600 / 1000 / 2000 米有里程碑提示。结算同时显示本次攀登和累计足迹。
- 台阶（借鉴《汉字双拼跳一跳》的梅花桩）：永远往前预铺 3 阶，最上面那阶一开始就在画面上缘之外，靠镜头上移把它"滚"进画面——既不会在画面中间凭空出现，也不会从天上掉下来。跳距 = 画布高 ×0.26（下限 152px，再小上面那阶就压到机器人脑袋上了），所以同屏能看到 2~3 阶加身后一阶。词不够铺满时自动少铺，绝不重复用词。已出现的浮岛保留原词和位置，跨组不清场。镜头按攀登高度平稳上移，不跟角色弧线回摆。

- **无限攀登是主入口**：不限每日新词数量，完成一组后自动补充新词，自动接续单元与等级，不弹出强制结算。可随时点“结束本次”；词库学完后轮换复习。
- **每日计划为可选模式**：默认每天约 5 个新词，优先加入到期旧词；额度用完后仍可复习，或直接改玩无限模式。每单元最多 20 词，两种模式共用学习进度。
- 每词先初练两次，再移入至少 **2分钟**的间隔队列；到期后第三次无答案提示地拼对，才达到本轮掌握。初练时优先穿插其他词，不连续刷第三遍。
- 到期回忆时使用“看答案”或完整联想卡，会作为提示练习，稍后再试，不直接增加掌握。提示后再收起或换目标，不会伪装成无提示回忆。
- 初练完成后可继续新词，不必等第三次才能前进单元；路线上的“掌握”统计仍以第三次为准。冷却期刷新或切单元不能跳过。
- 答错减1并显示答案，保留已正确输入的前缀；不用从头重打全部正确字母。
- 初学可见完整英文，第一次拼对后逐渐隐藏提示；另有看义回忆、听音拼词。
- 已掌握词首次间隔 1 天复习，后续成功复习间隔为 2、4、8、16、30 天。
- 电脑键盘可直接输入，也可点击屏幕字母键，输入框支持粘贴。请使用英文输入法；检测到非英文输入会明确提示。本轮不做手机端专门适配。
- 输入区与当前浮岛同步显示字母：绿色为已输入，光标指向下一位，红色标记错字；计数和进度条实时变化。输错保留正确前缀，拼对后完整单词保留到起跳完成。
- Backspace 退格（有错字时先清掉错字），Esc 清空；输入框或舞台焦点下可用 Tab 切换目标，也可点击浮岛或目标下拉框。
- “记忆联想”打开暖纸笔记页：共享情境示意图＋原创双语短句＋搭配＋关联词。浏览时暂停攀登；Esc关闭后回到原输入。回忆阶段先遮住答案线索，主动展开才提供提示。
- 听发音使用浏览器语音；是否有英文声音、是否需联网取决于系统与浏览器。不可用时可使用文字练习。
- 主动结束或每日计划完成后，显示练习词数、准确率、连击、积分和高度。无限模式在空中点结束时会先正常落地，再结算。
- 自动保存词汇进度、错词、到期日期、学习单元与模式。兼容导入旧版同源存档。

## 词库与路线

现有 **4,129 个独立词条**：NGSL 1.2 的2,809词＋TSL 1.2 的1,250词＋NGSL补充表净增50词＋项目商务形式补充20词。
官方另列的52个补充词中，March、May与主表同形，已补月份义而不重复计数。
补入 meeting、sales、shipping、minutes、premises、building 等实际形式，明确标为项目补充、不虚构官方词频。
中文释义、音标主要来自 ECDICT；来源、许可、下载文件和生成说明见 [data/SOURCES.md](data/SOURCES.md)。

| 学习目标路线 | 实际选词依据 | 词数 |
|---|---|---:|
| A1 入门基础 | NGSL 词频 1–500，加50个星期/月/数词补充 | 550 |
| A2 日常基础 | NGSL 词频 501–1200 | 700 |
| B1 核心提升 | NGSL 其余词 | 1609 |
| B2 托业进阶 | TSL 词频 1–650，加20个商务形式补充 | 670 |
| C1 高分拓展 | TSL 其余词 | 600 |

这些是本项目为练习安排的路线，**不是官方单词 CEFR 等级划分**。
词汇进度不能代替听力、阅读能力测评，也不能换算成托业考试分数。
当前交付聚焦词汇打字、回忆和复习；基础语法、完整听力题和限时阅读仍需配合专门练习。
词库逐行核对主表及补充表，无漏导、重复或词频错配；全部词条有中文、音标、词性、英文释义和可输入拼写。但“字段齐全”不代表所有释义和读音已完成人工校对，也不等于覆盖所有可能的托业用词和变形。

目前 **110词**有原创双语例句、搭配和关联词，使用8类共享SVG情境图；其余 **4019词**明确显示词典卡，尚未做完逐词图文精编。基础词如 work/time/name 已缩短为优先常用义，完整原词典义仍保留。

学习机制参考间隔练习、提取练习与图文词汇研究；**2分钟及跨天间隔是初版产品参数，不是“脑科学最佳值”**。研究、链接和局限见 [data/LEARNING_RESEARCH.md](data/LEARNING_RESEARCH.md)。本游戏尚未验证长期记忆效果或考试提分效果。

## 文件与开发

- `托业英语跳一跳.html`：可独立运行的离线游戏，已内嵌词库和逻辑。
- `index.html`、`app.js`：可编辑的页面与游戏逻辑。
- `learning.js`：三次掌握、可选每日计划、无限模式选词与复习调度。
- `ascent.js`：固定世界参照、地貌、绳尺与里程碑。
- `memory.js`：离线SVG情境图与遮词辅助；`data/memory-content.json`：原创例句、搭配和词汇联系。
- `data/extensions.json` / `data/lexical-corrections.json`：有标记的补充词及释义/缺失字段修正。
- `vocabulary.js`、`data/vocabulary.json`：生成后的词库。
- `data/sources/`：原始词表、词典与许可文件；游戏运行不需要加载此目录。
- `tools/build_vocab.py`：从原始数据生成词库；`tools/build_standalone.py`：生成离线单文件。

运行验证：

```powershell
node tools/test.js
python -X utf8 tools/audit_vocab.py
python -X utf8 tools/build_standalone.py
```

可选本地预览：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765/index.html 。使用本地预览地址时，保持同一地址以接续存档。

参考项目 `汉字双拼跳一跳` 保留原样。最新连续跳跃修复验收见 [qa/SEQUENTIAL_QA.md](qa/SEQUENTIAL_QA.md)，此前学习机制验收见 [qa/MEMORY_QA.md](qa/MEMORY_QA.md)，词库审计结果见 [qa/vocabulary-audit.json](qa/vocabulary-audit.json)。
